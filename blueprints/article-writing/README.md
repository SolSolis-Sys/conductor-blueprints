# Article Writing Pipeline

End-to-end article writing workflow: research, draft, structural edit (Pocock method), anti-slop pass, and publish.

## Inputs

| Name | Type | Required | Description |
|------|------|----------|-------------|
| source_path | string | Yes | Path to source draft, notes, or reference documents |
| target_path | string | Yes | Target output file path (markdown) |
| lang | string | Yes | Language: 'fr', 'en', or 'both' (bilingual) |

Tier: medium · ~$0.08/run

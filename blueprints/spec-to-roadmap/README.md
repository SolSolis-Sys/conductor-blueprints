# Spec to Roadmap Generator

Transform a project spec or ticket plan into a versioned roadmap with milestones, defining exactly what ships in each release.

## Inputs

| Name | Type | Required | Description |
|------|------|----------|-------------|
| source_path | string | Yes | Path to the source spec or ticket plan document |
| target_path | string | Yes | Path where ROADMAP.md will be written |
| current_version | string | Yes | Current version of the project (e.g., '0.1.0') |
| project_name | string | Yes | Name of the project |
